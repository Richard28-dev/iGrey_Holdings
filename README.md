## 🏛️ Overview

**iGrey Holdings** is an editorial luxury real estate platform built for high-net-worth individuals, family offices, and institutional investors seeking architectural distinction and long-term capital preservation across South India's premier postcodes.

Built on an architectural luxury aesthetic featuring a warm ivory palette (`#F8F6F0`), champagne gold accents (`#A6814E`), and deep charcoal typography (`#14161A`).

## ✨ Features & Architecture

* **Official Brand Identity**: Integrated official emblem mark, custom typography, and cinematic intro reveal animation.
* **Curated Portfolio Showcase**: Flagship property spotlight, category filtering (*Residences, Sky Penthouses, Commercial Assets, Private Estates*), interactive property dossiers, and high-resolution galleries.
* **About Section (Option 2)**: Floating luxury card layout with 4-pillar architectural cards (*Trust, Transparency, Quality, Personalized Service*).
* **Private Advisory Services**: Fiduciary acquisition advisory, development consultancy, private treaty marketing, and investment positioning.
* **Discreet Enquiries & Modal**: Direct consultation booking with instant feedback and portfolio dossier exploration.
* **Responsive Editorial Design**: Pixel-perfect layout across ultra-wide monitors, desktop, tablet, and mobile devices.

---

## 🛠️ Technology Stack

* **Framework**: React 18 + Vite + TypeScript
* **Styling**: Vanilla CSS with CSS custom property design tokens (warm ivory & champagne gold)
* **Animations**: Framer Motion for smooth micro-interactions and transitions
* **Icons**: Lucide React
* **Deployment**: Automated GitHub Pages via GitHub Actions (`.github/workflows/deploy.yml`)

## 🚀 Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Richard28-dev/iGrey_Holdings.git
   cd iGrey_Holdings
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start development server:**
   ```bash
   npm run dev
   ```

4. **Build production bundle:**
   ```bash
   npm run build
   ```
